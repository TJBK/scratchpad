# Scratchpad

Drawing tools for Foundry VTT (v13 and v14). I built this for my own gaming group, but anyone is welcome to use it.

## Features

- Freehand pen with round, square and flat brush tips, hardness, drop shadow, and textures (snow, moss, sand, dirt, stone, water, grass)
- Eraser that cuts through part of a line, or deletes whole drawings
- Shapes: line, arrow, rectangle, circle, triangle, diamond, pentagon, hexagon, star and free polygon, with Shift to snap
- Solid, dashed and dotted lines, with optional solid or 50% fill
- Multi-line text with font, size and alignment
- Lasso or click select to move and delete drawings
- Layers you can rename, reorder, hide, lock, or make GM only
- Private drawings only you can see
- Investigation board: formatted cards joined with string
- Other players see your strokes as you draw them
- Undo and redo
- One-click whiteboard scene
- Bake drawings into the scene background image

## Install

In Foundry, go to Add-on Modules, click Install Module, and paste this manifest URL:

```
https://github.com/TJBK/scratchpad/releases/latest/download/module.json
```

For the latest dev build, use this instead:

```
https://github.com/TJBK/scratchpad/releases/download/dev/module.json
```

## AI disclosure

AI coding tools help write this module's code, as allowed by section 4.4 of the [Foundry VTT AI Policy](https://foundryvtt.com/article/ai-policy). I understand, can explain, and maintain every part of the codebase. Scratchpad has no AI features and generates nothing with AI while you use it. Because AI was used in development, it doesn't qualify for Foundry's "Zero AI" tag.
